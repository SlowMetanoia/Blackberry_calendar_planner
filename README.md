# Вика — голосовой ежедневник

Управляйте личными задачами, напоминаниями и встречами
естественной речью или текстом. Ассистент понимает относительные даты, учитывает
контекст диалога и задаёт уточняющие вопросы, когда информации недостаточно.

## Что попробовать

- **Создать задачу или напоминание:** «Поставь задачу купить билеты до конца недели»,
  «Напомни мне завтра в 10 утра позвонить Ивану».
- **Создать встречу:** «Добавь встречу с командой завтра в 15:00».
- **Посмотреть планы за период:** «Что запланировано на эту неделю?»
- **Найти старую запись по смыслу:** «Я когда-то ставил задачу по договору, найди её».

Также доступны изменение и удаление голосом, отметка задач выполненными,
повторяющиеся задачи и встречи, предупреждения о пересечениях, уведомления,
история изменений и отмена действий. Данные сохраняются между запросами
и перезапусками; у каждого пользователя свой календарь.

Google Calendar и Web Push поддерживаются опционально; в публичном демо они выключены.
Напоминания доступны в центре уведомлений приложения.

## Архитектура и решения

**React/Vite → FastAPI → Redis/ARQ → LangGraph → PostgreSQL/pgvector.**

Распознавание речи — **GigaAM**, интерпретация запросов — **Qwen3.8**,
синтез голосового ответа — **Silero TTS**. В демо LLM, STT и эмбеддинги работают
через Polza, озвучка — локально на сервере.

LangGraph организует агентный цикл: модель читает календарь через инструменты,
уточняет запрос или формирует изменения. Сервер проверяет права и данные,
а затем применяет изменения атомарно. Неизменяемый журнал операций обеспечивает
историю и отмену. Фоновые воркеры отделяют длительную обработку от API;
гибридный поиск сочетает текстовые совпадения, триграммы и семантические эмбеддинги.

## Локальный запуск

Нужны Docker и Docker Compose. Скопируйте настройки:

```bash
cp .env.example .env
```

Для облачного запуска замените значения в `.env` на варианты из комментариев `#cloud`
и укажите ключи `LLM_API_KEY`, `STT_API_KEY`, `EMBEDDING_API_KEY`.
Для Polza используется один ключ во всех трёх переменных.

```bash
docker compose --profile release run --rm --build migrate
docker compose up --build
```

Интерфейс: [localhost:3000](http://localhost:3000).
Swagger API: [localhost:8000/docs](http://localhost:8000/docs).
При первом запуске загружаются модели guard и TTS.
Тесты, настройка моделей и интеграций — в [документации разработчика](docs/DEVELOPMENT.md).
